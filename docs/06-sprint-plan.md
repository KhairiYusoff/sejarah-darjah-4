# Pelan Sprint Projek

## Sprint 1: Persediaan dan pembelajaran
**Objektif:**
- Memahami struktur projek Expo
- Memahami app entry point
- Menyelesaikan workflow asas React Native

**Output:**
- Projek berjalan dengan lancar
- README jelas untuk pengguna dan pembangun
- Dokumen projek siap sebagai panduan

## Sprint 2: Kuiz asas
**Objektif:**
- Menyediakan data soalan
- Menyusun UI soalan dan jawapan
- Mencipta logik jawapan

**Output:**
- Pengguna boleh menjawab soalan secara berurutan
- Skor berubah berdasarkan jawapan

## Sprint 3: Feedback dan keputusan
**Objektif:**
- Menambah penerangan jawapan
- Menyediakan skrin keputusan
- Menyediakan butang ulang semula

**Output:**
- Pengguna mendapat maklum balas terus
- Keputusan akhir dipaparkan dengan jelas

## Sprint 4: Kemas kini kandungan
**Objektif:**
- Menambah lebih banyak soalan
- Menyusun berdasarkan topik Sejarah
- Meningkatkan bahasa dan kesinambungan kandungan

**Output:**
- Aplikasi lebih lengkap
- Kandungan lebih rapat dengan buku teks sekolah

## Sprint 5: Penambahbaikan UX
**Objektif:**
- Tingkatkan reka bentuk UI
- Perbaiki spacing, warna dan komponen
- Pastikan pengalaman lebih selesa untuk murid

**Output:**
- Aplikasi lebih menarik dan mudah digunakan

## Peraturan sprint
- Tiap sprint perlu mempunyai hasil yang boleh ditunjukkan
- Jangan panjangkan terlalu banyak tugas dalam satu sprint
- Fokus pada pembelajaran dan penambahbaikan yang boleh difahami
- Setelah selesai, semak semula untuk perbaikan kecil
