# Format Soalan

Gunakan format ini untuk setiap soalan.

```md
## U01-Q01

- Unit: Unit 1 - Mengenali Sejarah
- Subtopik: Pengertian Sejarah
- Status: `needs-review`

### Soalan

Apakah maksud sejarah?

A. Cerita rekaan
B. Peristiwa benar pada masa lalu
C. Senarai tempat
D. Lukisan moden

### Jawapan

B. Peristiwa benar pada masa lalu

### Penerangan

Sejarah berkaitan dengan peristiwa benar yang berlaku pada masa lampau.

### Sumber

- Unit 1, subtopik 1.1
- Pandai, topik 01-01
- Buku teks: halaman perlu disemak
```

## Peraturan penulisan

- Gunakan bahasa Melayu yang mudah difahami murid Tahun 4.
- Elakkan soalan yang mempunyai lebih daripada satu jawapan betul.
- Pilihan A, B, C dan D mesti munasabah.
- Jangan gunakan fakta yang belum ada dalam nota unit tanpa semakan.
- Kekalkan status `needs-review` sehingga sumber disahkan.
